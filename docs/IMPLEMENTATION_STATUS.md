# Статус реализации

## Текущая версия

Прототип: 0.1.0  
Язык: Rust  
Зависимости: только стандартная библиотека  
Назначение: проверка входных рыночных событий и первичный контур предотвращения ошибок.

## Реализовано

- Типизированное событие рынка с версией схемы.
- Раздельные временные метки события и получения в Unix milliseconds UTC.
- Представление котировки Bid/Ask целыми тиками и явным масштабом цены.
- Представление сделки целыми тиками и лотами.
- Проверка обязательных идентификаторов.
- Проверка временной целостности.
- Проверка положительности цены и масштаба.
- Проверка crossed quote (Bid > Ask).
- Обнаружение повторного event_id.
- Проверка строго возрастающей sequence внутри потока source/instrument.
- Структурированные защитные finding и уровни серьёзности.
- Unit и интеграционные smoke-тесты.
- CI workflow для fmt, Clippy и cargo test.

## Ограничения прототипа

- Это не полноценная торговая система и не торговый сигнал.
- Пока нет сериализации и сетевого API.
- Нет постоянного хранилища и восстановления состояния после перезапуска.
- Нет автоматической коррекции часов и оценки допустимого clock skew.
- Проверка sequence предполагает упорядоченную доставку внутри потока; политика обработки out-of-order событий ещё не реализована.
- Дедупликация хранит все идентификаторы в памяти и не имеет политики ограниченного окна.
- Нет проверки экономической целесообразности или реальной эффективности стратегий.
- CI настроен, но успешный запуск на конкретном коммите должен быть подтверждён фактическим результатом GitHub Actions.

## Следующие задачи

1. Независимый аудит контракта и политики временных меток.
2. Проверки тестами пропусков, повторов, out-of-order и восстановления потока.
3. Ограниченная по памяти политика дедупликации с явной семантикой.
4. Машиночитаемая схема внешнего контракта.
5. Детерминированный replay CLI.
6. Адаптер TRADINGCORE в режиме наблюдения.
